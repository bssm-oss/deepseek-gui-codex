# 기여 가이드

DeepSeek GUI Codex 한국어 튜닝판에 기여해 주셔서 감사합니다.

## 프로젝트 방향

이 저장소는 원본 DeepSeek GUI 오픈소스를 한국어 환경과 Codex OAuth 사용성에 맞게 튜닝한 버전입니다. 새 기능은 다음 방향을 지켜야 합니다.

- 기본 사용자 경험은 한국어입니다.
- 중국어 전용 문구나 로케일을 새로 추가하지 않습니다.
- DeepSeek API key provider와 Codex OAuth provider가 함께 동작해야 합니다.
- GUI는 Kun 단일 런타임 경계를 유지합니다.
- 사용자 파일 변경과 명령 실행은 승인/권한 정책을 존중해야 합니다.

## 기여 가능 영역

- 버그 수정
- 한국어 UI/문서 개선
- Codex OAuth provider 안정화
- Kun 런타임 통합 개선
- 테스트 보강
- 빌드/패키징 개선

## 작업 전 확인

```bash
npm install
npm run typecheck
npm test
npm run build
```

## 커밋 기준

- 한 커밋은 하나의 의도를 담습니다.
- 사용자에게 보이는 변경과 내부 리팩터링은 가능한 한 분리합니다.
- 문서, 테스트, 코드 변경을 기능 단위로 묶습니다.

## PR 체크리스트

- 변경 요약을 한국어로 설명했습니다.
- 관련 테스트를 실행했습니다.
- UI 문자열은 `src/renderer/src/locales/ko`에 반영했습니다.
- 중국어 문구를 새로 추가하지 않았습니다.
- 로컬 앱 패키징 변경이면 설치본 실행 또는 서명 검증을 확인했습니다.
